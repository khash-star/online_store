# Нэвтрэх болон Бараа Оруулах Заавар

## 🔐 Нэвтрэх

### 1. Login Page нээх:

Browser дээр:
```
http://localhost:5173/Login
```

Эсвэл URL bar дээр `/Login` гэж оруулах.

### 2. Бүртгэл үүсгэх (Register):

1. Login page дээр "Шинэ бүртгэл үүсгэх үү? Бүртгүүлэх" товч дээр дарах
2. Дараах мэдээлэл оруулах:
   - **Нэр** (шаардлагатай)
   - **Имэйл хаяг** (шаардлагатай)
   - **Нууц үг** (шаардлагатай)
   - **Утасны дугаар** (сонголттой)
3. "Бүртгүүлэх" товч дарна

### 3. Нэвтрэх (Login):

1. Имэйл болон нууц үгээ оруулах
2. "Нэвтрэх" товч дарна
3. Shop page руу автоматаар шилжинэ

---

## 📦 Бараа Оруулах (Admin)

### 1. Admin User байгаа эсэхийг шалгах:

Admin user байгаа эсэхийг шалгах:
- Admin email: `khashpay@gmail.com` (өмнө нь үүсгэсэн)
- Бусад user-үүд admin эрхгүй (зөвхөн `khashpay@gmail.com` admin)

### 2. PromoAdmin Page нээх:

Browser дээр:
```
http://localhost:5173/PromoAdmin
```

Эсвэл Shop page-ийн header дээр Settings (⚙️) icon дээр дарах.

### 3. Бараа нэмэх:

1. **"Бараа"** tab сонгох (PromoAdmin page дээр)
2. **"Бараа нэмэх"** товч дарна (урд талд байгаа Plus icon)
3. Дараах мэдээлэл оруулах:
   - **Нэр** * (шаардлагатай)
   - **Тайлбар** (сонголттой)
   - **Үнэ** * (шаардлагатай)
   - **Зураг URL** (эсвэл зураг upload хийх)
   - **Ангилал** (dropdown-аас сонгох)
   - **Хүйс** (Эрэгтэй, Эмэгтэй, Унисекс)
   - **Хэмжээ** (сонголттой)
   - **Өнгө** (сонголттой)
   - **Тоо ширхэг** (stock)
   - **Хүртээмжтэй эсэх** (toggle)
   - **Хөнгөлөлт (%)** (сонголттой)
   - **Affiliate link** (сонголттой)
4. **"Хадгалах"** товч дарна

### 4. Зураг Upload хийх:

1. Бараа нэмэх dialog-д "Зураг сонгох" товч дарна
2. Файл сонгох (зөвхөн зураг файл: .jpg, .png, .gif, гэх мэт)
3. Upload хийгдэх хүлээх
4. URL автоматаар form-д орох

### 5. Бараа засах/устгах:

- **Засах**: Барааны жагсаалт дээр Pencil (✏️) icon дарна
- **Устгах**: Trash (🗑️) icon дарна, баталгаажуулах

---

## ⚠️ Анхаарах зүйлс:

1. **Admin эрх шаардлагатай**: Зөвхөн admin user (khashpay@gmail.com) бараа нэмэх/засах/устгах боломжтой
2. **Backend server ажиллаж байх ёстой**: Backend server (`http://localhost:3000`) ажиллаж байгаа эсэхийг шалгах
3. **Database connection**: PostgreSQL database-д холбогдсон эсэхийг шалгах
4. **Authentication**: Нэвтрэхгүйгээр бараа оруулах боломжгүй

---

## 🔧 Асуудал гарвал:

### Backend server ажиллахгүй байвал:
```powershell
cd backend
npm run dev
```

### Database connection алдаа гарвал:
- PostgreSQL ажиллаж байгаа эсэхийг шалгах
- `.env` файл дээр `DATABASE_URL` зөв эсэхийг шалгах

### CORS алдаа гарвал:
- Backend `server.js` дээр CORS configuration засах (FIX_CORS_ERROR.md файл үзнэ үү)

### 401 Unauthorized алдаа гарвал:
- Нэвтэрсэн эсэхийг шалгах
- Token хадгалагдсан эсэхийг шалгах (Browser DevTools > Application > Local Storage)
